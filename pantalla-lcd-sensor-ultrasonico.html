¿De qué trata este proyecto?

En este proyecto se integra un sensor ultrasónico HC-SR04 con una pantalla LCD 16×2 mediante un módulo I2C (PCF8574), controlados por un Arduino UNO. El sistema mide en tiempo real la distancia a un objeto y la muestra en centímetros directamente en la pantalla LCD.

El sensor ultrasónico emite un pulso de sonido de alta frecuencia (40 kHz) y mide el tiempo que tarda el eco en regresar. Con ese tiempo, Arduino calcula la distancia usando la velocidad del sonido (340 m/s). La pantalla LCD muestra el resultado actualizado continuamente, creando un medidor de distancia digital en tiempo real.

¿Cómo Funciona el Sistema?

1

Emisión del Pulso Ultrasónico

Arduino envía un pulso HIGH de 10 microsegundos al pin TRIG del sensor HC-SR04. Esto activa el transductor emisor, que genera una ráfaga de 8 ciclos de sonido a 40 kHz (frecuencia inaudible para humanos). El pin TRIG se conecta al pin digital 9 del Arduino.

El pulso viaja por el aire a la velocidad del sonido (~340 m/s a temperatura ambiente) hasta chocar con un objeto y rebotar de regreso.

2

Recepción y Medición del Eco

El transductor receptor del HC-SR04 detecta el eco reflejado y pone el pin ECHO en HIGH durante el tiempo exacto que tardó el sonido en ir y volver. Arduino mide ese tiempo usando la función pulseIn(ECHO, HIGH), que retorna el tiempo en microsegundos.

3

Cálculo de la Distancia

Con el tiempo medido, Arduino calcula la distancia aplicando la fórmula física:

📐 Fórmula de Distancia

// Velocidad del sonido = 0.0343 cm/µs // El sonido recorre el camino de ida y vuelta, por eso se divide entre 2 distancia = duracion * 0.0343 / 2; // Ejemplo: si duracion = 3316 µs // distancia = 3316 × 0.0343 / 2 = 56.87 cm ≈ 56.92 cm
4

Envío a la Pantalla LCD por I2C

El resultado se envía a la pantalla LCD 16×2 a través del protocolo I2C usando solo 2 cables de datos (SDA y SCL). Arduino usa la librería LiquidCrystal_I2C para posicionar el cursor y escribir el texto. La pantalla se actualiza cada 500 ms con un lcd.clear() previo para evitar texto residual.

Código Arduino

El siguiente sketch de Arduino implementa toda la lógica del proyecto: lectura del sensor ultrasónico, cálculo de distancia y visualización en la LCD por I2C.

#include <Wire.h> #include <LiquidCrystal_I2C.h> // ─── Pines del sensor HC-SR04 ─────────────────────── const int TRIG_PIN = 9; const int ECHO_PIN = 10; // ─── LCD I2C: dirección 0x27, 16 columnas, 2 filas ── LiquidCrystal_I2C lcd(0x27, 16, 2); void setup() { pinMode(TRIG_PIN, OUTPUT); pinMode(ECHO_PIN, INPUT); lcd.init(); lcd.backlight(); lcd.setCursor(0, 0); lcd.print("Sensor Ultrason."); lcd.setCursor(0, 1); lcd.print("Iniciando..."); delay(2000); } void loop() { // 1. Limpiar el pin TRIG digitalWrite(TRIG_PIN, LOW); delayMicroseconds(2); // 2. Enviar pulso de 10 µs digitalWrite(TRIG_PIN, HIGH); delayMicroseconds(10); digitalWrite(TRIG_PIN, LOW); // 3. Medir duración del eco long duracion = pulseIn(ECHO_PIN, HIGH); // 4. Calcular distancia en cm float distancia = duracion * 0.0343 / 2.0; // 5. Mostrar en pantalla LCD lcd.clear(); lcd.setCursor(0, 0); lcd.print("Distancia:"); lcd.setCursor(0, 1); lcd.print(distancia, 2); lcd.print(" cm"); delay(500); }

💡 Funciones Clave Explicadas

  • digitalWrite(TRIG, HIGH/LOW): Controla el pin TRIG para generar el pulso de disparo de 10 µs que activa la emisión del ultrasonido.
  • pulseIn(ECHO, HIGH): Espera a que el pin ECHO se ponga en HIGH y mide cuánto tiempo permanece así (en microsegundos). Ese tiempo corresponde al viaje de ida y vuelta del sonido.
  • lcd.clear(): Borra toda la pantalla antes de escribir el nuevo valor. Esto evita que los dígitos anteriores queden visibles si el número tiene menos caracteres.
  • lcd.print(distancia, 2): Imprime el valor flotante con 2 decimales de precisión. El segundo parámetro indica cuántos decimales mostrar.
  • delay(500): Pausa de 500 ms entre mediciones. Se puede reducir para lecturas más rápidas, pero valores menores a 60 ms pueden causar interferencia entre el pulso emitido y el eco recibido.

⚙️ Conceptos Técnicos Importantes

  • Velocidad del sonido: A 20°C la velocidad es 343 m/s = 0.0343 cm/µs. Si la temperatura cambia, esta constante varía ligeramente. Para mayor precisión se puede usar un sensor de temperatura DHT11 y ajustar la fórmula dinámicamente.
  • Rango de medición del HC-SR04: El sensor funciona correctamente entre 2 cm y 400 cm. Por debajo de 2 cm el eco llega antes de que el sensor esté listo. Por encima de 400 cm la señal se atenúa demasiado.
  • Dirección I2C del módulo PCF8574: Las más comunes son 0x27 (PCF8574) y 0x3F (PCF8574A). Si la pantalla no muestra nada, usar un scanner I2C para verificar la dirección real del módulo.
  • Contraste de la pantalla: El potenciómetro en el módulo I2C controla el contraste. Si la pantalla está encendida pero no se ve texto, ajustar el potenciómetro girándolo lentamente hasta que aparezcan los caracteres.
  • Interferencia entre disparos: Esperar al menos 60 ms entre mediciones para que el eco de un disparo no se confunda con el disparo siguiente. El delay(500) del código garantiza esto con amplio margen.

Aplicaciones del Sistema

🚗
Sensor de Reversa

Detecta obstáculos traseros en vehículos y activa alarmas sonoras o visuales según la distancia al objeto, similar a los sensores de estacionamiento comerciales.

🤖
Robótica

Los robots autónomos usan sensores ultrasónicos para detectar paredes y obstáculos, permitiendo la navegación sin colisiones en espacios cerrados y laberintos.

💧
Nivel de Líquidos

Instalado sobre un tanque, mide la distancia desde la tapa hasta la superficie del líquido para calcular el nivel o volumen disponible sin contacto con el fluido.

🚪
Puertas Automáticas

Detecta la presencia de personas a cierta distancia para activar mecanismos de apertura automática de puertas, barreras o sistemas de control de acceso.
