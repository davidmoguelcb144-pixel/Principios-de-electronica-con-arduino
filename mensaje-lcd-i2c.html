LCD I2C

[ ARDUINO UNO · PANTALLA LCD 16×2 · MÓDULO I2C · TINKERCAD ]

◄ VOLVER AL INICIO

Introducción al Proyecto

Este proyecto demuestra cómo enviar y mostrar un mensaje de texto personalizado en una pantalla LCD 16×2 usando un Arduino UNO y el módulo adaptador I2C (IIC). Es uno de los proyectos fundamentales en el aprendizaje de Arduino, ya que combina comunicación serial, manejo de displays y bibliotecas externas.

El circuito fue diseñado y simulado previamente en Tinkercad, una plataforma gratuita de diseño y simulación de circuitos en línea. Esto permite verificar el funcionamiento del código y el conexionado antes de implementarlo en hardware físico, ahorrando tiempo y evitando errores de cableado.

Gracias al módulo I2C, la conexión entre el Arduino y la pantalla se reduce a solo 4 cables (VCC, GND, SDA, SCL), en contraste con los 10+ cables que requiere la conexión paralela directa.

Materiales Necesarios

Componentes requeridos para reproducir este proyecto tanto en simulación como en físico:

🔵
Arduino UNO R3
ATmega328P · 16 MHz

Microcontrolador principal. Ejecuta el código, gestiona la comunicación I2C y envía los datos de texto a la pantalla LCD.

  • Voltaje: 5V operación
  • Pines I2C: A4 (SDA) / A5 (SCL)
  • Memoria Flash: 32 KB
  • Conexión PC: Cable USB tipo B
📺
LCD 16×2
Display HD44780 · Verde/Negro

Pantalla de cristal líquido con retroiluminación verde y caracteres negros (o azul con caracteres blancos). Muestra 2 líneas de 16 caracteres ASCII cada una.

  • Caracteres: 16 cols × 2 filas
  • Controlador: HD44780
  • Voltaje: 5V
  • Tamaño caracter: 5×8 píxeles
🔌
Módulo I2C / IIC
PCF8574 · Adaptador LCD

Adaptador que se suelda o conecta a los pines de la LCD. Convierte la interfaz paralela de 8 bits del display en comunicación I2C de 2 cables, simplificando enormemente el cableado.

  • Chip: PCF8574 / PCF8574A
  • Dirección I2C: 0x27 o 0x3F
  • Cables datos: Solo SDA y SCL
  • Potenciómetro: Ajuste de contraste
🔲
Protoboard
Breadboard sin soldadura

Tablero de prototipos que permite realizar conexiones temporales sin soldadura. Ideal para proyectos educativos donde el circuito puede modificarse fácilmente.

  • Rieles: VCC (+) y GND (−) laterales
  • Filas: Conectadas horizontalmente
  • Corriente máx.: 1A por contacto
  • Voltaje máx.: 300V
🔗
Cables Jumper
M-M / M-H · Varios colores

Cables de conexión usados para interconectar los componentes. El código de colores facilita identificar cada señal y reduce errores de cableado.

  • Rojo: VCC (5V)
  • Negro: GND (tierra)
  • Verde: SDA (datos I2C)
  • Naranja/Amarillo: SCL (reloj I2C)
💻
Tinkercad
Simulador online · Autodesk

Plataforma gratuita de simulación de circuitos en el navegador. Permite diseñar, conectar componentes virtuales y ejecutar código Arduino antes de construir el circuito físico.

  • Acceso: tinkercad.com (gratuito)
  • Componentes: Arduino, LCD, sensores…
  • IDE integrado: Editor de código Arduino
  • Sin instalación: Corre en el navegador

Proceso de Desarrollo

Pasos seguidos para diseñar, simular e implementar el proyecto de mensaje en LCD I2C:

1

Diseño del Circuito en Tinkercad

El primer paso fue crear el circuito en Tinkercad. Se colocó el Arduino UNO, la pantalla LCD 16×2 y el módulo I2C en el área de trabajo virtual. Los cables se conectaron según el esquema: VCC y GND del módulo I2C a 5V y GND del Arduino, y las líneas SDA → A4 y SCL → A5.

La simulación permitió verificar que el cableado era correcto antes de escribir una sola línea de código, evitando posibles cortocircuitos o conexiones erróneas en el hardware real.

2

Programación del Arduino

Se escribió el código en el IDE integrado de Tinkercad (o en Arduino IDE). Se incluyeron las bibliotecas Wire.h y LiquidCrystal_I2C.h, se configuró la dirección I2C del módulo (0x27) y se programó el mensaje a mostrar en la pantalla.

La función lcd.print() permite enviar cualquier cadena de texto a la pantalla. Se puede mostrar texto en ambas filas usando lcd.setCursor(columna, fila) para posicionar el cursor.

💻 Código Arduino — Mensaje en LCD I2C

// Bibliotecas necesarias #include <Wire.h> // Protocolo I2C #include <LiquidCrystal_I2C.h> // Control de LCD vía I2C // Crear objeto LCD: dirección 0x27, 16 cols, 2 filas LiquidCrystal_I2C lcd(0x27, 16, 2); void setup() { lcd.init(); // Inicializar pantalla lcd.backlight(); // Encender retroiluminación lcd.clear(); // Limpiar pantalla // Escribir en la fila 0 (primera línea) lcd.setCursor(0, 0); lcd.print("Hello, World!"); // Escribir en la fila 1 (segunda línea) lcd.setCursor(0, 1); lcd.print("LCD I2C - Arduino"); } void loop() { // El mensaje se muestra de forma continua. // Se puede agregar scroll o animaciones aquí. }
3

Simulación y Prueba en Tinkercad

Con el circuito cableado y el código listo, se ejecutó la simulación en Tinkercad presionando el botón "Iniciar simulación". La pantalla LCD virtual mostró el mensaje programado en ambas líneas, confirmando que tanto el cableado como el código eran correctos.

Tinkercad simula el comportamiento real del hardware: si la dirección I2C no coincide, la pantalla no mostrará nada; si los pines SDA/SCL están invertidos, la comunicación fallará. Estos errores se detectan y corrigen fácilmente en la simulación.

📡 Conceptos Clave del Proyecto

  • Dirección I2C: El módulo PCF8574 tiene una dirección de 7 bits configurable mediante jumpers físicos. Las más comunes son 0x27 (PCF8574) y 0x3F (PCF8574A). Si la pantalla no muestra nada, verificar la dirección con un scanner I2C.
  • Función setCursor(col, row): Posiciona el cursor en una columna (0–15) y fila (0 = primera, 1 = segunda) específica antes de escribir texto. El parámetro columna indica el caracter donde comenzará la escritura.
  • Función lcd.print(): Envía una cadena de texto, número o variable a la posición actual del cursor. Acepta strings, enteros, floats y tipos char. Admite hasta 16 caracteres por línea.
  • Contraste del LCD: El potenciómetro integrado en el módulo I2C ajusta el contraste de los caracteres. Si la pantalla está encendida pero no se ve el texto, girar el potenciómetro lentamente hasta que aparezcan los caracteres.
  • Retroiluminación: Se activa con lcd.backlight() y se apaga con lcd.noBacklight(). En el módulo I2C hay un jumper que habilita o deshabilita el control de retroiluminación por software.
