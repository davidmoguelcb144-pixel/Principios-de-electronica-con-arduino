¿Qué es Arduino?

Definición simple

Arduino es una plataforma de electrónica de código abierto que combina hardware (una placa microcontroladora) y software (un editor de código) para crear proyectos interactivos. No necesitas ser ingeniero para usarlo: cualquiera puede empezar a aprender.

El corazón de Arduino es el microcontrolador (un mini-ordenador), que ejecuta programas llamados sketches. Puede leer sensores y controlar luces, motores, pantallas y mucho más.

Ventajas: Código abierto, comunidad gigante, miles de tutoriales, precio accesible, y compatible con cientos de componentes.

Componentes de Hardware
🔲

Microcontrolador

El chip principal que ejecuta tu código. En el Arduino Uno es el ATmega328P a 16 MHz.

⚡

Alimentación

Se puede conectar por USB (5 V) o por el conector de barril (7–12 V). Incluye reguladores internos.

📌

Pines Digitales

14 pines que pueden estar en HIGH (5 V) o LOW (0 V). Perfectos para botones y LEDs.

〰️

Pines Analógicos

6 entradas (A0–A5) para leer valores continuos de sensores: temperatura, luz, potenciómetros...

🔌

Puerto USB

Para cargar código a la placa y comunicarte con la computadora mediante el Monitor Serie.

💡

LED Integrado

El pin 13 tiene un LED ya montado. Perfecto para pruebas sin componentes extras.

🔁

Botón Reset

Reinicia el programa y lo ejecuta desde el principio.

🧩

Shields

Placas que se montan encima para añadir WiFi, motores, pantallas LCD, GPS, etc.

🔶

Cristal Oscilador

Cristal de 16 MHz que marca el ritmo de ejecución del chip.

Arduino IDE (Software)
🖥️

Editor de Código

Escribe tu código aquí, con resaltado de sintaxis y autocompletado. Gratuito y disponible para Windows, Mac y Linux.

📡

Compilador

Convierte tu código en un formato que entienda el microcontrolador, y lo carga a la placa por USB.

🔍

Monitor Serie

Ventana que muestra en tiempo real los datos que envía tu placa. Imprescindible para depurar.

📦

Gestor de Librerías

Descarga e instala librerías para sensores, pantallas, WiFi y mil cosas más con un clic.

Estructura de un Sketch

Las dos funciones mágicas

Todo programa Arduino tiene setup() (se ejecuta una vez) y loop() (se repite infinitamente).

EJEMPLO 
// Variables globales
const int LED = 13;
int velocidad = 500;

// Se ejecuta UNA sola vez al arrancar
void setup() {
  pinMode(LED, OUTPUT);
  Serial.begin(9600);
  Serial.println("¡Arduino listo!");
}

// Se repite CONTINUAMENTE
void loop() {
  digitalWrite(LED, HIGH);  // Enciende
  delay(velocidad);
  
  digitalWrite(LED, LOW);   // Apaga
  delay(velocidad);
}
Funciones Principales
⚙️

pinMode()

Configura un pin como INPUT o OUTPUT. Se llama en setup().

📤

digitalWrite()

Enciende (HIGH) o apaga (LOW) un pin digital.

🔎

digitalRead()

Lee si un pin está HIGH o LOW. Ideal para botones.

〰️

analogRead()

Lee un valor analógico (0–1023) de un sensor conectado a A0–A5.

📉

analogWrite()

PWM: simula una salida analógica con valores 0–255. Ideal para controlar brillo o velocidad.

⏱️

delay() / millis()

delay(ms) pausa. millis() devuelve el tiempo sin bloquear el código.

🗺️

map()

Convierte un valor de un rango a otro: map(valor, 0, 1023, 0, 255)

📡

Serial

Serial.begin(), Serial.print(), Serial.read() para comunicación.

🎚️

constrain() / abs()

Limita valores dentro de rangos. constrain(x, 0, 255)

Modelos de Arduino
🟦

Arduino Uno

La placa de referencia. Perfecta para aprender. 14 pines digitales, 6 analógicos. Muy documentada.

🟩

Arduino Nano

Mismo chip que el Uno pero compacto. Cabe perfectamente en una protoboard. Ideal para proyectos pequeños.

🔵

Arduino Mega

Para proyectos grandes: 54 pines digitales, 16 analógicos. Mucho espacio de memoria.

📶

Arduino MKR WiFi

WiFi integrado. Ideal para IoT y proyectos conectados. Moderno y poderoso.

⚙️

ESP32

Más barato, WiFi + Bluetooth integrados. Compatible con Arduino IDE. La favorita para IoT.

🎛️

Arduino Due

ARM Cortex-M3, 84 MHz. Incluye DAC real. Perfecto para audio y procesamiento de señales.
