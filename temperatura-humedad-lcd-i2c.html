Introducción al Proyecto

Este proyecto implementa un sistema de monitoreo ambiental basado en Arduino que mide en tiempo real la temperatura y la humedad relativa del ambiente. Los datos se muestran de forma continua en una pantalla LCD 16×2 conectada mediante el protocolo de comunicación I2C, lo que simplifica enormemente el cableado.

El sensor DHT11 captura las lecturas ambientales y las envía al microcontrolador ATmega328P del Arduino, que procesa los datos y los formatea para su visualización. En la imagen del circuito se puede apreciar la lectura de 26.70 °C de temperatura y 41.00% de humedad relativa, demostrando el correcto funcionamiento del sistema.

Componentes del Circuito

Información detallada sobre cada componente utilizado en este proyecto:

🔵
Arduino UNO
ATmega328P · 16 MHz

Microcontrolador de código abierto basado en el chip ATmega328P. Es el cerebro del proyecto: lee el sensor, procesa los datos y envía la información a la pantalla LCD vía I2C.

  • Voltaje de operación: 5V
  • Pines digitales I/O: 14 (6 PWM)
  • Pines analógicos: 6
  • Memoria Flash: 32 KB
  • SRAM: 2 KB
  • I2C (SDA/SCL): Pines A4 / A5
🌡️
Sensor DHT11
Temperatura & Humedad

Sensor digital de temperatura y humedad relativa de bajo costo. Utiliza un protocolo de comunicación serial de un solo hilo para transmitir las lecturas calibradas al microcontrolador.

  • Rango temperatura: 0°C – 50°C (±2°C)
  • Rango humedad: 20% – 80% HR (±5%)
  • Voltaje de operación: 3.3V – 5.5V
  • Tiempo de muestreo: 1 segundo mínimo
  • Resolución: 1°C / 1% HR
  • Protocolo: 1-Wire (señal digital)
📺
LCD 16×2
Display HD44780

Pantalla de cristal líquido con retroiluminación azul y caracteres blancos. Capaz de mostrar 2 líneas de 16 caracteres cada una. Controlada por el chip HD44780, compatible con módulo I2C.

  • Caracteres: 16 columnas × 2 filas
  • Retroiluminación: LED azul
  • Voltaje de operación: 5V
  • Controlador: HD44780
  • Tamaño caracter: 5×8 puntos
  • Interfaz nativa: 4 u 8 bits paralelo
🔌
Módulo I2C
PCF8574 · Adaptador LCD

Adaptador que permite controlar la pantalla LCD usando solo 2 cables de datos (SDA y SCL) en lugar de los 6–10 cables que requiere la conexión paralela directa. Usa el expansor de I/O PCF8574.

  • Chip: PCF8574 / PCF8574A
  • Protocolo: I2C (Two-Wire Interface)
  • Dirección I2C: 0x27 o 0x3F (ajustable)
  • Cables necesarios: Solo VCC, GND, SDA, SCL
  • Potenciómetro: Ajuste de contraste integrado
  • Jumper: Control de retroiluminación
🔲
Protoboard
Tablero de conexión sin soldadura

Permite montar circuitos electrónicos temporales sin necesidad de soldadura. Sus filas y columnas internas están eléctricamente conectadas, facilitando el prototipado rápido.

  • Filas centrales: Conectadas horizontalmente (a-e / f-j)
  • Rieles laterales: VCC (+) y GND (−)
  • Material: Plástico ABS con clips metálicos
  • Corriente máx.: 1A por contacto
  • Voltaje máx.: 300V
🔗
Cables Jumper
Macho-Macho / Macho-Hembra

Cables de conexión flexible utilizados para interconectar los componentes en la protoboard y el Arduino. Se usan distintos colores para identificar fácilmente cada señal.

  • Rojo: VCC / Alimentación positiva
  • Negro/Café: GND / Tierra
  • Amarillo: Señal de datos (DHT)
  • Verde: SDA (datos I2C)
  • Azul/Blanco: SCL (reloj I2C)

¿Cómo Funciona el Sistema?

⚡ Protocolo I2C — Inter-Integrated Circuit

  • ¿Qué es I2C? Es un protocolo de comunicación serial síncrono que permite conectar múltiples dispositivos usando solo 2 líneas: SDA (Serial Data) para los datos y SCL (Serial Clock) para la señal de reloj. Fue desarrollado por Philips (ahora NXP) en 1982.
  • Ventaja principal: Con el módulo I2C, la LCD 16×2 (que normalmente requiere 6 a 10 cables) se conecta con solo 4 cables. Esto simplifica enormemente el cableado y libera pines del Arduino para otros componentes.
  • Direccionamiento: Cada dispositivo I2C tiene una dirección única (0x27 o 0x3F en el módulo PCF8574). El Arduino envía primero la dirección del dispositivo destino antes de transmitir los datos.
  • Velocidad: El bus I2C estándar opera a 100 kHz (modo estándar) o 400 kHz (modo rápido). Para esta aplicación se usa el modo estándar, suficiente para actualizar la pantalla LCD con datos del sensor cada segundo.

🌡️ Funcionamiento del Sensor DHT11

  • Sensor capacitivo de humedad: El DHT11 contiene un sensor capacitivo cuya capacitancia varía según la humedad del aire. Esta variación es convertida a una señal digital por el circuito interno del sensor.
  • Termistor NTC: Para medir temperatura, el sensor incluye un termistor de coeficiente de temperatura negativo (NTC), cuya resistencia disminuye al aumentar la temperatura. El circuito interno convierte este valor a lectura digital.
  • Protocolo de comunicación: El DHT11 usa un protocolo de un solo hilo (1-Wire). El Arduino envía una señal de inicio, el sensor responde con 40 bits de datos: 16 bits de humedad, 16 bits de temperatura y 8 bits de verificación (checksum).
  • Tiempo de respuesta: El sensor requiere al menos 1 segundo entre lecturas para garantizar datos estables y precisos. La biblioteca DHT de Arduino gestiona automáticamente estos tiempos de espera.

💻 Código Arduino (Estructura Base)

// Bibliotecas necesarias #include <Wire.h> // Comunicación I2C #include <LiquidCrystal_I2C.h> // Control LCD vía I2C #include <DHT.h> // Lectura del sensor DHT // Configuración de pines y objetos #define DHTPIN 2 // Pin digital del sensor DHT #define DHTTYPE DHT11 // Tipo de sensor DHT dht(DHTPIN, DHTTYPE); LiquidCrystal_I2C lcd(0x27, 16, 2); // Dirección I2C, columnas, filas void setup() { lcd.init(); // Inicializar pantalla LCD lcd.backlight(); // Activar retroiluminación dht.begin(); // Inicializar sensor DHT } void loop() { float temp = dht.readTemperature(); // Leer temperatura (°C) float hum = dht.readHumidity(); // Leer humedad (%) lcd.setCursor(0, 0); // Fila 1, columna 1 lcd.print("Temp:"); lcd.print(temp); lcd.setCursor(0, 1); // Fila 2, columna 1 lcd.print("Humedad:"); lcd.print(hum); delay(2000); // Esperar 2 segundos }
  • Wire.h: Biblioteca nativa de Arduino que implementa el protocolo I2C, necesaria para que el módulo LCD se comunique con el Arduino.
  • LiquidCrystal_I2C.h: Biblioteca de alto nivel que abstrae el control del LCD vía I2C, permitiendo usar funciones simples como print() y setCursor().
  • DHT.h: Biblioteca que maneja el protocolo de comunicación del sensor DHT, incluyendo los tiempos de señal, lectura de bits y validación de datos.
